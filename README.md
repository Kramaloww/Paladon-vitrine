# Paladon — site de présentation

Site statique (HTML, CSS, JavaScript), sans dépendance ni étape de build.

## Aperçu en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Contenu

- `index.html` : page d'accueil (français)
- `en/` : version anglaise
- `mentions-legales.html` : mentions légales
- `assets/` : styles, scripts, police et images

Les chiffres affichés sur le site sont fictifs.
