**Français** · [English](README.en.md)

**Le copilote du quotidien qui reste chez vous.**

Paladon réunit vos finances, vos placements, vos actualités, vos tâches et vos alertes dans une seule application. Installée sur votre propre machine et épaulée par une IA locale, elle garde vos données là où elles doivent être : chez vous.

🌐 **[paladon.net](https://paladon.net)**

## Pourquoi Paladon

- **Tout au même endroit** : patrimoine, budget, objectifs d'épargne, bourse, actualités et tâches.
- **Vos données chez vous** : auto-hébergé, accessible uniquement par un réseau privé, jamais exposé sur Internet.
- **Une IA qui explique, sans inventer** : les chiffres viennent de calculs testés, l'IA locale les met en mots.
- **Aucune IA dans le cloud** : le modèle tourne sur votre machine, rien ne part chez un fournisseur d'IA.

## Statut

Paladon est un projet personnel, pas encore distribué. L'application est pour l'instant en français.
